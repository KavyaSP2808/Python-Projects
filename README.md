# Python Projects 

This repository contains a collection of beginner-friendly Python projects created to practice programming concepts and build useful applications. Each project focuses on core Python fundamentals and demonstrates practical problem-solving skills.

# 📂 Projects Included
## 1. Contact Book 

A simple contact management system that allows users to:

* Add new contacts
* View saved contacts
* Search for specific contacts
* Delete contacts
## 2. Simple Calculator 

A basic calculator that performs:

* Addition
* Subtraction
* Multiplication
* Division

Designed to demonstrate functions and user input handling.

## 3. Task Manager Project 

A task management application where users can:

* Add tasks
* View tasks
* Mark tasks as completed
* Delete tasks

Great for understanding lists and file handling.

## 4. Weather App 

A weather application that:

* Fetches real-time weather data
* Displays temperature, conditions, and location details
* Built to practice working with APIs and external libraries.

## Technologies Used

* Python

* Google Colab

* Basic Python libraries (requests, etc.)

## Purpose

The goal of this repository is to:

Strengthen Python fundamentals
Build real-world mini projects
Improve problem-solving skills
